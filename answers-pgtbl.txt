The PTE contains the physical page number (PPN) and permission bits. The main permission bits are `V`, `R`, `W`, `X`, and `U`, which indicate whether the page is valid, readable, writable, executable, and accessible from user mode.

- `0x5B`: `R-X-U`, so these are user-readable and executable text/code pages.
- `0x17`: `RW--U`, so this is a user-readable and writable data page.
- `0x07`: `RW--`, with `U=0`, so it is not accessible from user mode.
- `0xD7`: `RW--U` with the accessed (`A`) and dirty (`D`) bits set.
- `0xC7`: `RW--` with `U=0`, corresponding to the trapframe.
- `0x4B`: `R-X-` with `U=0`, corresponding to the trampoline.
- `0x0`: the PTE is invalid (`V=0`), so the virtual page is unmapped.

The virtual pages do not have to map to consecutive physical pages. For example, `0x0` maps to `0x87F22000`, while `0x1000` maps to `0x87F1F000`.
